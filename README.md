# Les Bestioles Savantes

Jeu éducatif autonome (PWA) pour un enfant de 5 ans, niveau grande section → CP.

- **8 univers** : Animaux & Nature, Lettres & Mots, Maths & Logique, Formes & Tailles, Royaume des dragons, Laboratoire de la nature, Village des amis, Español.
- **Récompenses** : 5 pièces par bonne réponse, 50 pièces = 1 carte, carnet de **151 animaux réels** (communes, rares, super rares, brillantes).
- **Voix** : consignes lues en français, mots espagnols lus avec une voix espagnole (synthèse vocale du téléphone).
- **Niveaux** qui s’adaptent tout seuls dans chaque univers ; réglages parents (prénom, compagnon, remise à zéro par univers).
- Fonctionne **hors connexion** une fois ouverte. La progression est gardée sur l’appareil.

Tout le jeu tient dans `index.html`. Pour l’installer sur Android : ouvrir le lien dans Chrome → menu ⋮ → « Installer l’application » / « Ajouter à l’écran d’accueil ».
